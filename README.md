# 다이노 파이터즈 (Dino Fighters)

만 4세 조카와 아빠가 같은 PC에서 **게임패드 2개**로 즐기는 **웹 로컬 대전 격투게임**.
설치·로그인·서버 매칭 없이 브라우저에서 웹주소만 열면 바로 플레이한다.

- 플랫폼: PC 브라우저 웹게임 (정적 배포)
- 대전: 한 기기에서 로컬 2인 대전 + 1인 CPU전
- 입력: 게임패드 2개 (보조로 패드+키보드, 키보드 2인)
- 캐릭터: 공룡 12종 (익룡 게스트 프테라노돈 포함)
- 그래픽: 2D HD 카툰 컷아웃 리깅 + 핵심 포즈 스프라이트

> 게임 기획과 그림은 ChatGPT에서 준비하고, 실제 코딩은 GenCode에서 진행한다.
> 기준 문서는 **《다이노 파이터즈 제작 계획서 v1.0 (2026-09-30)》** 이며, 아래 규칙·수치·id·프롬프트 단계는 이 문서를 따른다.

## 기술 스택

- **TypeScript** + **Vite** (빌드/개발 서버)
- **Canvas 2D** 렌더링 (작은 의존성, 설치 불필요한 정적 배포)
- 60Hz 고정 스텝 시뮬레이션과 렌더링 분리

## 실행 방법

```bash
npm install      # 의존성 설치 (최초 1회)
npm run dev      # 개발 서버 실행 후 브라우저에서 안내된 주소 열기
npm run build    # 정적 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm run typecheck
```

## 배포

정적 호스팅(GitHub Pages 등)에 `dist/`를 올린다. `vite.config.ts`의 `base: './'`
설정으로 하위 경로(`/dinosaur-fight-hyun/`)에서도 에셋이 정상 로드된다.

## 조작 (계획서 1절)

| 동작 | 게임패드 | 1P 키보드 | 2P 키보드 |
| --- | --- | --- | --- |
| 이동 | 방향키 / 왼쪽 스틱 | A D | ← → |
| 점프·웅크리기 | 위·아래 | W S | ↑ ↓ |
| 약공격 | 왼쪽 얼굴 버튼 (index 2) | F | J |
| 강공격 | 위쪽 얼굴 버튼 (index 3) | G | K |
| 특수기 | 오른쪽 얼굴 버튼 (index 1) | H | L |
| 확인 | 아래쪽 얼굴 버튼 (index 0) | Enter | 오른쪽 Shift (또는 NumEnter) |
| 뒤로 | 오른쪽 얼굴 버튼 (index 1) | Esc | 오른쪽 Ctrl |
| 일시정지 | Start (index 9) | Esc | 오른쪽 Ctrl |

- 키보드 하나로 두 사람이 함께 할 때 확인·뒤로·일시정지 키가 겹치지 않도록 플레이어별로 나눠 두었다.

- 패드의 확인 버튼을 누르면 참가하며, 누른 순서대로 1P·2P로 배정된다.
- 패드 연결이 끊기거나 창 포커스를 잃으면 즉시 일시정지하고 눌린 키 상태를 비운다. 확인 버튼으로 재개한다.

## 전투 규칙 (계획서 2~3절, 시험판 기준)

| 항목 | 값 |
| --- | --- |
| 한 경기 | 45초 라운드 · 2라운드 선승 |
| 시간 종료 | 남은 체력 **비율** 비교 (최대 체력이 달라도 공정) |
| 무승부 | 동시 KO 또는 체력 비율 동일 → 승수 없음 · 재라운드 |
| 방어 | 지상 대기·이동에서 상대 반대 방향 입력 시 자동 가드 |
| 가드 처리 | 약·강 피해 0, 특수기 20%, 체력은 1 아래로 내려가지 않음 |
| 게이지 | 시작 50 · 초당 4 · 명중 8 · 피격 4 · 최대 100 (특수기 사용 시 100 소모) |
| 기술 프레임 | 약 6/4/14 (피해 10) · 강 14/6/24 (18) · 특수 24/10/38 (28) |
| 넉백 | 약 70 · 강 120 · 특수 180 디자인 px |
| 피격 경직 | 약 12 · 강 20 · 특수 28 프레임 |
| 타격 정지 | 약 3 · 강 5 · 특수 7 프레임 (양측 동일) |
| 입력 보관 | 공격 버튼 새 누름을 최대 120ms 보관 |
| 연속 피격 보호 | 3회 연속 명중 후 30프레임 무적 (이동 가능) |

대전 화면에서 **F3**를 누르면 판정 상자(hurtbox 파랑 / hitbox 빨강)를 볼 수 있다.

## 에셋

2026-09-30 다이노 아티스트가 다시 그린 12종 마스터(티라노·트리케라 v2 + 나머지 10종 재배치본)와 티라노 전용 포즈 5종을 `public/assets/characters/{id}/`에 반영했다. 이전 ChatGPT 프로토타입 에셋은 폐기했다.

| 파일 | 용도 |
| --- | --- |
| `master_side.png` | 이동·대기·공격 기본 스프라이트 (2048×1536 RGBA, 접지 y=1280) |
| `poses/{heavy,special,hit,down,victory}.png` | 전용 포즈 (현재 티라노사우루스만 있음) |
| `portrait.png` | 선택 화면 초상 (512×512, 마스터에서 머리를 잘라 만든 임시 크롭) |
| `rig.json` | 캔버스·기준점·실측 경계·포즈 정렬 좌표·사용 가능 플래그 |
| `parts/` | 컷아웃 파츠 (아직 게임에서 쓰지 않음) |

원본 아트는 계획서 11절대로 **화면에 보일 키의 약 2.7배(슈퍼샘플)** 로 그려져 있다. 그래서 `rig.json`의 `master.box.h`(실측 실루엣 높이)와 `characters.json`의 `displayHeight`로 배율을 계산해 그린다(`src/rendering/rig.ts`의 `spriteScale`). 실측값이 없는 1:1 아트는 배율 1로 그린다.

`rig.json`의 `usable` 플래그가 `false`인 포즈는 로드하지 않고 마스터의 절차적 변형으로 대체한다.

## 알려진 제약

- **초상은 임시 크롭**: `portrait.png`는 아티스트가 준 초상이 아니라 마스터에서 머리 부분을 잘라 만든 임시본이다. 정식 초상이 오면 교체한다.
- **전용 포즈는 티라노사우루스만**: 나머지 11종은 포즈 파일을 `usable: false`로 두어 마스터 변형으로 움직인다. 파츠·포즈 단계에서 채운다.
- 컷아웃 파츠(`parts/`)는 아직 의미 이름·pivot·offset·drawOrder가 없어 관절 리깅 전이다.
- 경기장 4종은 아직 단색 임시 배경이다(프롬프트 4).
- `alternatePalette.skin`(2P 보조색)은 `palette.json`이 오기 전까지 대표색을 파랑 쪽으로 섞은 임시값이다.
- 공중 약공격·다단 연출·웅크리기 전용 기술은 아직 없다. 웅크리기는 자세를 낮추기만 한다.
- 상단·하단 가드 구분, 방어력 계수는 첫 버전 범위가 아니라 넣지 않았다.
- 이펙트(먼지·별·충격파)와 사운드는 프롬프트 6에서 추가한다.
- 키보드 2인은 확인·뒤로·일시정지 키를 플레이어별로 분리했다(1P Enter·Esc / 2P 오른쪽 Shift·Ctrl). 화면에서 키를 다시 지정하는 UI는 아직 없다.

# Beta release scope

Approved candidate5f81a24 is merged with normal history, preserving prior main.
Public beta includes approved terminal artwork, uniform victory/down rendering,
KO gravity and terminal cleanup. Existing standard game's selection/combat/input
rules remain the default; this is not approval of the contact-expansion experiment.

Contact candidate, audit and comparison entry points are DEV-only. Production builds
emit index.html only. Query parameters cannot enable the10-species contact expansion
on Pages. Experimental source/tests remain in Git history for continued development;
they are not a public feature. No3D change.

Physical gamepads, TV and speakers NOT TESTED. Lifecycle smoke tests with1HP fixtures
are explicitly not full-health combat balance tests. Beta is not the final product.

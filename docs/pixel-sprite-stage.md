# 12종 도트 스프라이트 재생기 (개발 비교판)

작성 2026-10-29 · 대상: 아티스트 12종 1차본(A·B·C 패키지, 669장)

이 문서는 **재생 방식**을 기록한다. 공개 베타(`main`)와 판정 값은 이 작업에서 바뀌지 않았다.

## 1. 계약 (디렉터 확정)

| 항목 | 값 |
| --- | --- |
| 셀 | 502×304 원본 픽셀 |
| 발 기준선 | footY = 298 (셀 좌표) |
| 기준 x | anchorX = 251 (셀 중심) |

프레임마다 다른 것을 허용하는 값은 **잘라낸 그림 사각형과 그 안의 발 기준점**뿐이다.
크기·기준선은 12종 전부 고정이다. `src/rendering/pixel/SpeciesSprite.ts`의 `parseSpriteManifest`가
이 값을 검사하고, 하나라도 다르면 그리지 않고 예외를 던진다(반쯤 맞는 그림으로 화면을 채우면
손교정 여부를 판단할 수 없기 때문).

## 2. 상태 매핑표 (12종 공통)

게임 상태 → 아티스트 클립. 12종 모두 같은 표를 쓰고, 클립마다 프레임 수·지속 틱이 다르다
(아티스트 JSON의 `ms`를 60Hz 틱으로 환산).

| 게임 상태 | 아티스트 클립 | 트리거 | 재생 |
| --- | --- | --- | --- |
| 대기 `idle` | `idle` | `idle`·`crouch`·`guard`·`stun` | 반복 |
| 걷기 `walk` | `walk` | `walk` | 반복 |
| 점프 `jump` | `jump` | `jump`이면서 지면 밖(`onGround=false`) | 1회 |
| 약공격 `light` | `light_attack` | `attack` + `move.kind==='light'` | 기술 길이에 맞춰 1회 |
| 강공격 `strong` | `heavy_slam` | `attack` + `kind==='heavy'` | 기술 길이에 맞춰 1회 |
| 특수 `special` | `special` | `attack` + `kind==='special'` | 기술 길이에 맞춰 1회 |
| 피격 `hit` | `hit` | `hit`이면서 지면 | 1회(HP가 줄 때마다 처음부터) |
| 공중버둥 `flail` | `flail` | `hit`이면서 공중 · `held` · `fallen` | 반복 |
| 다운 `down` | `down` | `down` | 1회, 마지막 그림 유지 |
| 승리 `victory` | `victory` | `victory` | 반복 |

티라노 프레임 예시(티라노): 대기 4장/42틱 · 걷기 8장/46틱 · 점프 6장/38틱 · 약 8장/42틱 ·
강 8장/53틱 · 특수 9장/54틱 · 피격 3장/19틱 · 공중버둥 4장/20틱 · 다운 3장/39틱 · 승리 4장/57틱.

### 재생 규칙 세 가지

1. **공격 3종은 기술 프레임 수에 그림 전체를 맞춘다.** 아티스트 원본 리듬(프레임별 `ms` 비율)은
   유지하고, 전체 길이만 `moveTotalFrames`에 맞춘다. 그래야 기존 판정 상자가 열리는 틱에 그림의
   내지르는 자세가 온다. 판정 쪽 숫자는 하나도 바꾸지 않았다.
2. **정지(hitstop)·컷인 동안 시계가 멈춘다.** 타격감 연출 중 그림만 계속 흐르면 접촉이 어긋나 보인다.
3. **피격은 HP가 줄 때마다 처음부터.** 같은 피격이 연달아 들어와도 매번 맞는 자세가 나온다.

## 3. 자산 포장

아티스트 프레임 PNG는 그대로 쓰지 않는다. `scripts/build-species-sprites.py`가
프레임마다 **알파 실제 경계를 다시 재서** 잘라 8열 시트로 묶고, 잘라낸 그림 안의 발 기준점을
`anchor`로 남긴다(아티스트 JSON의 bbox 선언은 검증에만 쓰고, 그림은 실측으로 자른다 —
v1에서 25/26 선언과 실물이 달랐던 문제를 되풀이하지 않기 위해).

```bash
python3 scripts/build-species-sprites.py /tmp/pkgA /tmp/pkgB /tmp/pkgC --out dev-art/species
python3 scripts/render-sprite-board.py --out <evidence dir>   # 상태 보드 PNG + 계측표
```

결과: `dev-art/species/<폴더>/{manifest.json, sheet.png}` + `index.json` (12종 669장).
`dev-art`는 `public` 밖이라 배포 빌드에 들어가지 않는다(빌드 산출물에 `pixelStage` 문자열 0건 확인).

## 4. 여는 법 (개발 전용)

`npm run dev` 후 `http://127.0.0.1:5178/?pixelStage=1` 또는 시작 화면 위
**‘개발용 12종 도트 스프라이트 비교판’** 링크.

- 렌더러 선택: `도트 12종(신규)` / `기존 부위 렌더러` — 같은 경기를 유지한 채 그림만 바뀐다.
- 연출/흔들림/이펙트 체크박스: 기본 꺼짐. A/B는 이 상태로 보는 것이 맞다.
- 상태 표: 10상태별 클립 프레임 수·틱.
- 자세 관찰: 12종 × 10상태를 4배로 그려 준다(발 기준선 고정, 실전 판정과 별개).
- `패널 접기`: 캡처할 때 화면을 가리지 않게.

## 7. 배경 도트 규격 (아티스트 전달용)

화면 기준 해상도는 1920×1080 고정이다. 캐릭터 도트가 4배 격자이므로 배경도 같은 격자여야 한다.

| 항목 | 값 |
| --- | --- |
| 배경 원본 격자 | **480×270** (= 1920÷4 × 1080÷4) |
| 확대 | 정수 4배만 → 1920×1080. 반픽셀·비정수 배율 금지 |
| 캐릭터가 서는 지면선 | 원본 **y = 225** (= 화면 900) |
| 레이어 수 | 3 (원경 / 중경 / 지면) |

| 레이어 | 원본 크기 | 화면 크기 | 지면선 | 비고 |
| --- | --- | --- | --- | --- |
| 원경 `sky` | 512×270 | 2048×1080 | 지평선은 y 150~210 사이 | 시차 4% → 좌우 16px씩 여유 |
| 중경 `mid` | 544×270 | 2176×1080 | **레이어 아래끝을 y=225에 정확히** 맞추고 그 아래는 투명 | 시차 14% → 좌우 32px씩 여유 |
| 지면 `ground` | 640×45 | 2560×180 | **레이어 위끝이 y=225** | 시차 30% → 좌우 80px씩 여유 |

- 세 레이어 모두 가로로 이어 붙이지 않는다(반복 타일 아님). 여유분은 시차 이동용이다.
- 중경·지면은 PNG-32(위쪽 투명), 원경은 PNG-24.
- 이번에 받은 `bg_pixel_8_v1`은 640×360 **한 장**이고 배율이 ×3이라 캐릭터(×4)와 픽셀 크기가
  섞인다. 위 3레이어 규격으로 다시 그려야 게임에 붙일 수 있다.
- 지면선 y=225는 캐릭터 발 기준선과 같은 값이다. 배경 지면이 이 선에서 1px이라도 어긋나면
  캐릭터가 뜨거나 파고든 것처럼 보인다.

## 8. 도트 배경 3레이어 (2026-10-29 추가)

`bg_layers_jungle_v1`을 실제로 연결했다. `dev-art/stages/<stage>/{layers.json, *_640x360.png}`.

- 화면 폭이 640의 **정수배일 때만** 그린다(`pixelScaleFor`). 1920×1080이면 k=3, 비정수면 기존 배경으로 넘어간다 — 아트를 축소·확대해 맞추지 않는다.
- 레이어는 **가로 타일**로 깐다. 시차로 밀려도 빈 곳이 생기지 않으므로 블리드 폭은 필요 없다(이음선은 원본 그림의 몫).
- 배경 지면선(원본 298)을 캐릭터 발 높이(게임 900)에 맞춰 프레임 위치를 정한다. 지면선 정렬 때문에 위에 남는 6px는 어둡게 채운다.
- 시차는 엔진 값(원경 0.04 · 중경 0.14 · 지면 0.30)을 쓴다. 아티스트 `layers.json`의 scrollX(0.25/0.6/1.0)와 다르다 — 엔진 쪽이 맞고, 0.25 기준으로 잡은 960 블리드는 과하다.
- 기존 8종 무대는 2048×1143 JPG라 정수배가 아니므로 손대지 않았다(도트 배경은 새 3레이어 세트에만 적용).

현재 연결된 무대: `jungle` 1곳. 나머지 7종은 아티스트 3레이어 세트가 오면 같은 폴더 규약으로 추가하면 된다.

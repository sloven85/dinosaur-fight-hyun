## 반영 방식

- 공격 3기술만 납품 `frames_1p` 8장으로 교체. 나머지 클립(idle·walk·jump·hit·flail·down·victory)은
  기존 시트 픽셀을 그대로 다시 포장했다(리샘플 없음).
- 시트는 8열 격자, 칸 502×304, 52프레임(8×7). 프레임은 알파 bbox로 자르고 **발 기준선(298)까지
  투명 여백을 포함**해 `anchor.y === h`로 맞췄다 → 접지 게이트 유지, 납품의 발끝 295~296 정렬.
- 공격 클립의 `artMs`는 기술 위상(준비/판정/회수)에 맞춰 재배분했다. 경계는 **내림**으로 잡아
  접촉 프레임이 반드시 5번 칸(접촉 칸)에 걸린다 — 반올림하면 경계가 접촉 시각을 살짝 넘어
  4번 칸이 그려지는 사례가 나왔다(프테라 약공격 실측 214.0ms vs 214.3ms).
- 2P 시트는 납품 `frames_2p`를 쓰지 않고 1P에서 규칙대로 1:1 치환해 다시 만들었다
  (trex는 `dev-art/palettes/trex.json` 표, 나머지는 `build-p2-all-species.py`와 같은 색상 +150° 규칙).
  납품 2P를 그대로 섞으면 종마다 치환 규칙이 달라 "색 하나 → 두 색" 충돌이 난다(`p2Palette.test.ts`).

## 함께 고친 엔진 1건

프테라 약공격의 접촉 자세가 판정 앞끝보다 **9.8px(2.45 아트px) 길어서**, 기존 런타임은 앞으로 미는
보정만 있어 그림이 판정 밖으로 삐져나왔다. 게이트 표는 이미 음수 보정(당김)을 전제로 PASS를 내고
있었으므로 런타임도 같은 부호 규칙을 쓰게 고쳤다(`ContactAlign.contactOffsetArt`).
접촉 순간 주둥이가 정확히 판정 앞끝에 선다. 피해·사거리·판정 수치는 불변.

# 안킬로 특수기 재생 수정 (2026-10-31)

마스터 지적(8244623): 인게임에서 안킬로 special 이 f0~f3 만 나오고 f4·f5(풀기·복귀)가 빠진 채 서기로 넘어간다.

## 원인 — 그림이 아니라 스크립트

- 클립은 6장(`manifest.clips.special.frames = [22..27]`, 7틱씩 42틱)이고, 기술 스크립트는 `frames:146`.
  재생기는 공격 중 그림을 **기술 프레임 수(146)에 비율로 맞춰** 고른다(f0 0~24, f1 25~48, f2 49~73, f3 74~97, f4 98~121, f5 122~146).
- 그런데 스크립트 `events` 에 **`{"f":97,"type":"end"}`** 가 있었다. 반격이 안 터진 실행(헛휘두름)은 97프레임에서 기술이 끝나
  → 상태가 idle 로 바뀌고 → 재생 클립도 idle 로 갈아 끼워진다. 즉 f4·f5 가 그려질 구간(98~146)이 통째로 잘렸다.
- 같은 구간에 있던 것들이 함께 죽어 있었다: 후속타(109~116, 26 피해·unguardable·launch), 궤적 그림(108), 충격 연출(112).
  엔진 계측(수정 전): `선언 146f · 실제 마지막 f96 · 그린 클립 4/6장 · 피해 7@f80`.

## 수정

1. `src/data/moves.json` — `ankylosaurus_special` 의 `{"f":97,"type":"end"}` 삭제. 기술이 선언한 146프레임을 끝까지 돈다.
2. 후속타·궤적·충격 연출에 `onCounter: true` — **반격 성공 실행에서만** 터진다(헛휘두름 피해는 지금과 같은 땅 강타 1회).
3. `src/combat/moveScript.ts` — `ScriptHit.onCounter`, `ScriptEvent` 의 `CounterGate` 추가.
4. `src/combat/Match.ts` — 판정·사건 해석에서 `onCounter && !run.countered` 면 건너뛴다.
5. `workspace/dino-moves/build_moves.py` — 같은 내용으로 생성기 원본도 맞춤(실행하지 않음: 손으로 다듬은 다른 기술 값이 덮인다).
6. 회귀 테스트 `src/combat/ankySpecialPlayback.test.ts` — 헛휘두름 6/6장·후속타 없음, 반격 성공 f109 후속타.

## 바뀐 것 / 안 바뀐 것

- 바뀐 것: 헛휘두름(반격 실패)의 기술 길이 97f → **146f**. 즉 구르고 풀어서 서는 동작이 끝까지 나오고, 그만큼 경직이 길다
  (146f ≈ 2.43초. 이전 97f ≈ 1.62초). 피해·사거리·판정 상자·접촉 프레임 수치는 불변.
- 그대로: 반격 성공 경로(성공 프레임 100 으로 건너뛰고 f109 후속타) — 기존 동작과 동일.

- `triceratops_heavy`: 선언 104f · 실제 마지막 f69 · 클립 **3/4장**(마지막 복귀 프레임 잘림)

트리케라 강공격도 같은 방식(잘린 구간을 살리고 후속 피해는 `onCounter`/구간 잠금)으로 고칠 수 있다. 이번 지시 범위가 아니라 손대지 않았다.
